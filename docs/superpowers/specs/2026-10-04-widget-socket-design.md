# Widget socket design

User supplied and authorized this redesign on 2026-10-04. It supersedes the lease/CLI IPC sections of the original framework design. Preserve the verified animation, dismissal, placement and logical scaling behavior.

One Quickshell 0.3.0 runtime serves `$XDG_RUNTIME_DIR/workstation-widgets/control.sock`. Private directory and socket are owner-only (no group/other bits), owned by the session UID. Systemd creates RuntimeDirectory with explicit mode 0700 and UMask=0077, so the socket is created 0700 (0177 breaks Quickshell internal directory creation). The earlier startup chmod to 0600 was removed: it added an external process and a restart loop on failure without changing who can connect. The real probe confirmed concurrent peers, independent parsers, EOF on close/kill, responsive Gio async reading, and replacement of a stale socket after SIGKILL.

Wire version 2 uses newline-delimited JSON objects. First frame: `{protocolVersion:2,type:"hello",role:"adapter"|"cli"}`. Adapter receives `{protocolVersion:2,type:"snapshot",state}` immediately and after each state revision. CLI receives `{protocolVersion:2,type:"hello",pid,instanceId}`. Requests: `{protocolVersion:2,type:"command",seq,method,args:{...}}`; replies: `{protocolVersion:2,type:"reply",seq,ok,result,error?}`. A positive integer seq correlates replies; widget requestId remains independent. Malformed frames/roles are rejected. Adapter commands: toggle, hideAll, placed, placementFailed, setGeometry, setAnimations. CLI commands: status, show, hide, toggle, hideAll. Role restrictions apply before dispatch. Each CLI connection issues one command. No IpcHandler or qs ipc remains.

One adapter owns placement. A new adapter replaces the previous connection without closing already open widgets; old EOF and late commands cannot affect the new owner. Current adapter EOF closes all windows immediately and records lastError. No adapter means all windows closed: attempts to open are rejected. Reconnection clears the disconnect error. Client uses cancellable asynchronous Gio socket reads and writes, verifies server UID, reconnects with 250/500/1000/2000ms backoff and stops retrying on disable. Healthy idle has no client timers; command timeouts and reconnect delays exist only while needed.

Model adapter state is `{connected:boolean}`; events ADAPTER_CONNECTED, ADAPTER_DISCONNECTED and TIMEOUT replace LEASE and TICK. Controller schedules one single-shot timer for nextDeadline(state), the earliest preparing-window placement deadline (2000ms). No deadlines means no timer. Animation completion continues to be driven by QML animations.

Manifest schema remains 1 and adds unloadOnClose:boolean default false. True unloads Loader only when closed; next opening loads again. Context and scaling remain framework responsibilities. runtime.json schema 2 retains qsPath for owner diagnostics, manifestPath, adapter and socketPath; socketPath may use the exact `$XDG_RUNTIME_DIR/` prefix, otherwise must be absolute. Runtime and manifest move to xdg.dataFile under workstation/widgets. QML configuration stays in xdg.configFile/quickshell.

Service retains session lifecycle, GNOME Wayland guard and Restart=on-failure. Python CLI uses only socket IPC; start/stop/restart still invoke systemctl. Diagnostics verify socket permissions, peer identity, state, service PID and adapter connection.

Acceptance: model/protocol/client tests; real headless runtime socket lifecycle including concurrent CLI, takeover, EOF and timeout; Wayland integration preserving placement/size/scale; idle 60s CPU and wakeup measurements; no CLI Quickshell subprocess; ws check no new warnings after adapter activation. Native GNOME caches extension modules, so final installed-code GUI checks require normal logout/login when replacing a loaded extension. Never force session termination.
