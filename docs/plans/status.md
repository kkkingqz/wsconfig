# WSCONFIG — ИТОГ ПРОЕКТА

Состояние на 2026-10-15. Машина mbp16 воспроизводима и восстанавливается:
ядро wsconfig собирается в Nix store, конфигурация лежит в отдельном
репозитории, CI зелёный. Не доведены три линии: проверка установки с нуля,
живой backup на tower и второе железо (Legion Go, wsgnomebox).

Подробности — в планах (ws help roadmap, ws help plan-v2) и историях
слоёв (`docs/history/`).

## 1.2. wsconfig v2

Цель плана v2 достигнута: неизменяемое ядро в `/nix/store`, конфигурация —
отдельный репозиторий, одна команда `ws`, одно применение `ws apply`.

| Этап | Что | Когда |
|---|---|---|
| 0–1 | база для сравнения выходов, чистка legacy | 2026-10-14 |

| 3 | каталоги, выбор хоста в файлах хоста (yes/no/ask) | 2026-10-14 |
| 4 | факты хоста в `host.toml` | 2026-10-14 |
| 5 | ядро из Nix store, в PATH одна `ws` | 2026-10-14 |
