# apt packages the core needs on every host on top of a standard Ubuntu
# desktop: without them a module of the core does not work (ws help
# architecture-v2, 4). The packages the user wants on every host are in
# apt.txt of the configuration, those of one host in hosts/<host>/apt.txt.
# One package per line; `ppa:OWNER/NAME` adds an Ubuntu PPA first;
# `purge:NAME` purges a package of the standard install (bootstrap.sh).
# Packages are installed without their recommends; `rec:NAME` installs NAME
# with them (a metapackage whose content is Recommends). apt takes
# recommends only when it installs a package: on a host that already has
# NAME, remove it and run bootstrap.sh again.
# Host lists also take `source:NAME` (the repository
# hosts/<host>/apt/NAME.sources with its key NAME.asc, installed as
# /etc/apt/sources.list.d/ws-NAME.sources and /etc/apt/keyrings/ws-NAME.asc)
# and `arch:NAME` (dpkg --add-architecture), both before the packages.
# Installed by bootstrap.sh; `ws check apt` compares with apt-mark showmanual.
# The lists by facts (lib/apt.bash): real machines system/apt-machine.txt
# (boot is not "container"), virtual machines virt/apt.txt (vm = true),
# native Steam steam/apt.txt (nativeSteam = true), Game Mode session
# gaming/apt.txt (gameMode = true).
